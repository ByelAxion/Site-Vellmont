# Vellmont Studio

Site institucional/portfólio da Vellmont, feito em React + Vite.

## Rodar

```bash
npm install
npm run dev
```

Depois abra o endereço mostrado pelo Vite.

## Personalizar os projetos

Abra `src/main.jsx` e altere os campos `url` dentro de `projects` para os links reais de cada site.

A logo usada no site está em `public/vellmont-logo.jpeg`.
